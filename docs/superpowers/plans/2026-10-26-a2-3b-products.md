# A2-3b Product Operations Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add safe, undoable product stock, visibility, creation, duplication, deletion, and ordering operations to the admin product list.

**Architecture:** Keep all database mutations in `lib/admin/products.ts`, each in one transaction with one `audit_log` entry and a settings timestamp touch. Thin Server Actions authenticate, invoke the operation, invalidate the menu tag, and redirect. The client product-list controls use accessible buttons and in-page native `<dialog>` elements; the existing edit form remains the source for product fields.

**Tech Stack:** Next.js App Router/Server Actions, React 19, TypeScript, mysql2 (MariaDB/MySQL), Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-25-thth-qr-menu-design.md` sections 4.2 and 4.4.

## Global Constraints

- Every menu-changing Server Action calls `requireAdmin()` and `updateTag("menu")`.
- All UI errors are Turkish and exposed with `role="alert"`; confirmations are page-visible `<dialog>`, never `confirm()`.
- Each operation writes exactly one audit row and `undoLast` reverses the top operation, including a deleted product's variants.
- Sold-out times use `Europe/Istanbul`; indefinite means `2099-12-31`.
- Migration entries are append-only; snapshots retain only the latest 25 and exclude no menu fields beyond the future WiFi requirement.
- Stable product-control selectors are `data-testid="product-<operation>-<id>"`.

## Review Focus

- 00:20, 07:50, 08:00 and 23:59 Istanbul-time stock choices must target the stated local opening instant.
- Multiple operations in one category must keep a deterministic contiguous ordering after move, duplicate, add, delete, and undo.
- A delete snapshot must capture the pre-delete menu and never exceed 25 records.
- Undoing delete must restore all variant rows and original product properties.
- An invalid/missing product or category must roll back without a partial audit row or changed menu timestamp.
